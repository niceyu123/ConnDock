# Phase 2 主机管理与核心 UI

用户已确认 Phase 1 验收后自动继续；Phase 1 结果见 `PHASE1-VALIDATION.md`。保持当前中性黑白配色、原生导航、设备布局和 Rust SSH 架构。

1. 使用显式关闭自动 CloudKit 的版本化 SwiftData 模型保存主机与分组。字段包含稳定 UUID、编辑时间/版本、分组、收藏、最近连接与凭据引用；不保存密码、私钥或终端内容。
2. Keychain 独立保存认证材料，默认不参与同步。连接表单明确选择是否保存凭据；重连优先按引用读取，丢失/拒绝访问时要求重新输入。写入失败不得回落为明文存储。
3. 连接表单支持新增、编辑、保存及连接；侧栏与 iPhone 列表展示真实持久数据，支持分组、搜索、收藏、最近与删除。已保存主机和正在运行的会话分离，切换标签保留会话；删除配置不伪造断线事件。
4. 继续复用 macOS Inspector/SFTP 容器及移动端独立布局；补齐新增 UI 中英文本、加载/错误/空状态和两种配色。终端外观设置延续独立本机保存。
5. 先测试磁盘重开保持、凭据引用、主机/分组操作及保存失败，再完成实现；实际验证系统 Keychain、双端构建、三端运行和 SSH 回归。

本阶段不启用 iCloud、不接入 SFTP/监控/MCP，不创建远端认证配置或云服务。保留用户图标和既有未提交工作，不自动提交或推送。
