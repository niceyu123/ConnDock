# Phase 3 代码复核与处置

2026-10-27。依据 `requirements.md` 与 `PHASE3-PLAN.md` 对 Rust、UniFFI、Swift 产品模型、界面和真实服务脚本执行一次独立的只读复核。仓库无首次 Git 提交，不虚构 base/head diff；复核按明确文件范围进行，没有读取测试秘密或启动额外构建。

## 已处理的主要问题

1. **陈旧目录操作**：编辑、删除与下载捕获触发时的父目录，加载期间禁用旧列表操作；目录已改变则返回本地化错误。删除确认显示绝对路径。原生专项检查错误目录下的同名选择不会删除当前文件。
2. **桥接取消**：已核查 UniFFI 0.32.2 的异步 continuation 不自动传播 Swift Task 取消。增加显式 `RemoteOperation`，打开 SFTP/文件时可同步取消；每步检查 Swift 取消标记。已建立文件继续使用自身取消信号。
3. **迟到 Channel 确认**：打开由有界 owner 接收确认，调用方已取消时关闭迟到 Channel；20 秒无法确认则关闭连接，不让未知会话无限积累。
4. **目录句柄**：RAII 关闭已取得的句柄；OPENDIR 已发送但回复未到时，取消关闭该浏览 Channel。协议级回归先复现未发 CLOSE，再验证 Drop 会发出 CLOSE。
5. **覆盖属性**：保留普通权限和 UID/GID，不恢复 setuid/setgid 等特殊位。不能保留时明确失败。真实 OpenSSH 0755/0640 回归先失败后通过。
6. **最终提交**：增加“正在完成”阶段并禁用主动取消；进入 rename 后不再把用户取消当作确定回滚。网络中断时提示提交结果不确定，要求刷新检查。
7. **写测试隔离**：Phase 3 Apple 写测试强制检查回环与脚本 fixture 标记，并先创建独占 UUID 子目录；创建失败即退出，所有写入/清理限制在该目录。
8. **主工具栏上传**：底部在“传输”页签时，主工具栏上传会切回文件页，以呈现系统选择器。
9. **监控基准**：增加独立 Linux 命令的 CPU 与网络计数窗口比较，而不只检查范围和非空。

此外，真实截图复核发现移动 Sheet 在外观切换时未更新。原生 trait 断言先失败，修正后重跑三端专项并替换误标颜色的旧截图。异常断开也已增加状态回归，与用户取消分开。

macOS 完整 UI 的失败辅助功能树还确认：容器级 identifier 被 SwiftUI 传播到路径和所有子按钮，覆盖了子控件原标识。已移除这两个无须标记的外层 identifier，路径控件单独提供完整路径 label/value；保留原有交互断言重跑，不降低验收要求。

## 保留边界

- 断点续传、远程编辑、双栏、iCloud 与 MCP 不在本阶段，不提前开发。
- 新文件使用 0600 是安全默认；覆盖保留普通权限，ACL、xattr 等高级属性不属于已实现能力。
- 2 GiB 与内存数据来自 Rust 真实服务专项，不能推广为三端 UI 的大文件峰值实测；三端原生专项使用约 1 MiB 文件验证产品链路。
- 应用突然退出可能留下私有缓存；网络断开可能留下未提交的远端 `.part`，不会承诺无法实现的跨网络回滚。完成/清除任务的正常生命周期会释放本地临时副本。
- 未通过的 macOS UI 结果与环境打断分别保留，不以静态复核或原生模型测试替代实际窗口交互验收。最终判断见 `PHASE3-VALIDATION.md`。
