## 现状与环境

Phase 2 macOS 补充验收已完成。现有 Rust/Tokio/russh 拥有真实 SSH/PTY，SwiftTerm 与 UniFFI 已在三端验证。SFTP、监控仍为空面板。本机具备 Xcode 27.1、Apple Silicon 和 iPhone/iPad 模拟器，磁盘可用约 214 GiB。Docker CLI 与 Docker Desktop 已安装，初查引擎未启动；只将隔离的 Linux 容器作为真实测试环境，不为产品增加 Docker 功能或持久服务。

## 实现顺序

1. 先为 Linux 指标解析、两次 CPU/网络采样、计数器重置及文件路径/分块边界建立失败测试，再实现 Rust 模块。
2. 在现有已认证连接上打开独立 SSH Channel，用固定命令采集监控，用固定版本 russh-sftp 处理文件；不复用交互 PTY 执行命令，不重新保存密码或绕过主机验证。
3. UniFFI 提供异步目录/文件/监控 API；每次传输使用固定上限的数据块。Rust 不接受本机文件路径，由 Swift 在用户授权的本机资源上进行流式读写。
4. 实现列目录、上级/主目录、创建目录、重命名、删除空目录/文件、上传、下载、进度、取消和失败重试。覆盖和删除通过明确的原生确认完成；不递归删除目录。上传先写临时文件，再提交目标，失败不把不完整数据显示为完成。
5. 三端复用会话级文件与监控状态。macOS 使用现有底部面板和 Inspector；iPhone/iPad 使用触控 Sheet。Swift Charts 显示真实时间序列，默认 5 秒刷新、可暂停；隐藏/离开面板和断开连接停止采集。
6. 新界面、错误与确认接入简中/英文 String Catalog；保持独立设计的浅深主题。

## 验收

- `scripts/verify.sh`：格式、翻译、Rust 单元测试/Clippy、四架构库、macOS/iOS 构建与基础测试。
- 临时真实 OpenSSH：目录和特殊字符文件名、权限/同名冲突、传输、取消、断网、重试及交互终端并行。
- 至少 2 GiB 上传和下载，比较流式摘要并测量内存，不能以小文件或只生成稀疏文件代替真实传输。
- Linux `/proc` 与 `df` 的真实采样，与同一服务内基准读取比较；macOS 服务应明确报告非 Linux 不支持。
- macOS/iPhone/iPad 的桥接、面板生命周期与运行截图。物理设备、最低系统和正式签名未具备时明确列出限制。
- 所有测试凭据、临时数据、终端/远端内容截图只放忽略的 `build/` 或临时目录；报告实际结果和未完成项，不将 Mock 当作真实验收。

完成后停在 Phase 3，等待后续阶段指令。

## 执行记录与决策

- 监控解析和 SFTP 路径/偏移测试已先失败后通过。真实 Linux 容器与本机 OpenSSH 的基础操作通过；Linux 2 GiB 双向传输逐字节校验通过。证据在 `build/phase3-*.log`，最终结果统一汇入阶段验收记录。
- 采用已有两个 Cargo crate 内的独立模块，不增加空壳 crate。新依赖仅为固定的 russh-sftp 3.0.1；不升级既有 SSH/FFI 版本。
- 真实断网后无法依赖原连接删除远端临时文件；本阶段保证不提交不完整目标，可能遗留带 `.sshclient-` 前缀的临时上传，明确报告。取消且连接仍可用时会尝试关闭并删除它。
- 下载在 App 私有缓存中分块落盘，完成后由系统保存/导出窗口选择本机目的地，不把本机文件路径交给 Rust。临时副本由本进程任务状态持有，清除任务时释放；崩溃后的缓存清理由系统管理。
- macOS 文件权限从“用户选择文件只读”改为“用户选择文件读写”，仅用于用户在系统保存窗口明确选定的目的地；仍保留 App Sandbox，不增加全盘权限。
- 最初截图发现移动工具 Sheet 打开期间外观未更新，已增加真实呈现控制器断言复现；修复后三端专项通过，已替换此前误标浅深的截图。
- macOS 完整 UI 已通过连接表单、私钥系统选择器、指纹、键盘、SFTP 新建/上传/下载/系统导出/删除和实时外观切换；最终证据见 `PHASE3-VALIDATION.md`。
- 最终只读复核增加了目录请求取消时的句柄释放检查；保持原子覆盖策略、独立 Channel 和传输分块上限。
