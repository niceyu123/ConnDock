# Phase 7 Implementation Plan

> **For agentic workers:** Use executing-plans for the split workspace and dispatching-parallel-agents for the independent SSH Config importer. Follow failing tests → implementation → regression verification.

**Goal:** 交付可用的终端分屏与安全 SSH Config 导入。

**Architecture:** WorkspaceState 管理标签组合及焦点，原生 TerminalView 保持每会话一个实例。导入器纯解析文本，通过 HostLibrary 保存选中的非机密主机配置。

**Tech Stack:** Swift 6、SwiftUI、SwiftTerm、SwiftData；沿用固定依赖。

**Spec:** docs/superpowers/specs/2026-10-28-phase7-design.md；docs/requirements.md。

## Global Constraints

- macOS arm64 only；iOS/iPadOS arm64。
- UI 文案统一 Localizable.xcstrings，每项 zh-Hans/en。
- 凭据和终端输出不得进入普通数据库、日志或 Git。
- 不修改现有 MCP 审批、SSH 信任或 iOS 后台恢复边界。

## Review Focus

- 分屏同一 native view 不得挂载两次，重组不重连或广播输入。
- 鼠标/键盘焦点与底部工具的目标必须一致。
- 关闭、取消分屏和 compact 切换不得复活会话。
- 配置中的命令、Include、Match、代理选项不可静默转成错误直连。
- 大文件、非法端口、重复导入不能造成不受控内存、隐式覆盖或部分未报告保存。
